内存卫士 0.6.0 安装版

安装程序将复制软件到你选择的目录，并创建开始菜单入口。
“创建桌面快捷方式”默认勾选，安装完成后可在桌面双击“内存卫士”启动。

内存清理需要管理员权限，启动时可能出现 Windows 授权提示。
安装程序不会自动开启“登录时启动”，如有需要请在软件右键菜单中开启。
如果你之前使用免安装版，请先从托盘退出旧版；如旧版开启过登录启动，
请在安装版中关闭再重新开启，以更新登录启动任务指向的位置。

可在 Windows 设置的应用列表或开始菜单中卸载。
卸载会移除程序和本次安装创建的快捷方式，保留个人设置，方便重装。

本程序基于 Windows Memory Cleaner，按 GNU GPL v3 发布。
