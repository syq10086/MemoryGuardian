会关闭正在使用的软件吗？+

程序不会主动结束进程或关闭窗口。清理工作集与缓存后，软件再次读取数据可能短暂卡顿，磁盘活动也可能增加；不能保证所有任务都不受影响。重要的渲染、计算或实时任务运行期间，建议暂时关闭自动清理。

已经超过阈值，为什么还没有自动清理？+

内存占用需要连续达到阈值 30 秒，且不处于冷却期。手动或自动清理后都会进入冷却，默认 10 分钟。新版球上会显示倒计时或“冷却 X 分”，右键可查看详细状态。建议从默认的 80%、均衡模式开始使用。

为什么有管理员盾牌或“未知发布者”提示？+

部分系统内存清理操作需要管理员权限，因此快捷方式带有盾牌。当前版本尚未购买或获得受信任的代码签名证书，Windows 可能显示“未知发布者”或 SmartScreen 提醒。请确认下载来源，可对照本页校验值和源码核验；不确定时先取消运行，无需关闭系统安全防护。

装不上或提示缺少 .NET，怎么办？+

安装包会检查 .NET Framework 4.8.1。请从 微软官方网站 ↗ 获取运行时；较早的 Windows 10 版本可能需要先更新系统。暂不提供 macOS、Linux 或手机安装版。

内存清理在本机执行，不需要注册或上传内存数据；点击作者主页、GitHub 或更新链接会打开外部网站。安装版可在 Windows“设置 → 应用”或开始菜单中卸载，个人配置会保留。免安装版退出程序、关闭其登录启动选项后，可删除程序文件。
